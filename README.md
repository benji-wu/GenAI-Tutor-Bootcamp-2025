請用簡單的語言向國中生解釋什麼是量子電腦。  
- 限制三段以內、每段不超過 50 字  
- 使用生活常見比喻  
- 避免直接抄寫百科

> 就像你在玩彈珠機時，一顆球可以同時在兩個軌道上搖擺，直到你觀察它。  
> 這讓它在某些計算上比普通電腦更快、更有效率。

## ✨ 提示 3：程式生成型 - 判斷質數

**Prompt：**  
請使用 Python 寫一段程式碼，判斷使用者輸入的數字是否為質數。  
- 對象為初學者，請加入註解  
- 不使用進階語法或套件

**AI 回應：**
```python
# 判斷是否為質數
num = int(input("請輸入一個數字："))
if num > 1:
    for i in range(2, num):
        if num % i == 0:
            print("不是質數")
            break
    else:
        print("是質數")
else:
    print("不是質數")
