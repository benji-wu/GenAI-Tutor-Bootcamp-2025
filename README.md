## Prompt 3: Prompt 3：程式生成型 - 判斷質數

### 🔹 提示內容：

請用 Python 撰寫一段程式，功能是判斷使用者輸入的數字是否為質數。
- 對象為程式初學者。
- 請為每一行加入註解。
- 避免使用進階語法或外部套件（如 NumPy）。

### 🔸 AI 回應結果：



```python
# 判斷是否為質數
num = int(input("請輸入一個數字："))
if num > 1:
    for i in range(2, num):
        if num % i == 0:
            print("不是質數")
            break
    else:
        print("是質數")
else:
    print("不是質數")
```

**分析：** 使用基礎語法與註解，初學者友善。
